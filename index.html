GateKeeper

Multi-tenant API gateway and rate limiter. The hard part: two requests must never spend the same token.

  • Token bucket written as one atomic Redis Lua script, so concurrent requests cannot race
  • Proven under load: 20 simultaneous requests give an exact allowed / rejected split, every run
  • SHA-256 hashed API keys shown once, instant revocation, per-tenant quotas, live analytics

Dental X-ray classifier

ResNet-18 transfer learning that flags caries on panoramic X-rays, with Grad-CAM heatmaps showing where the model looked. Trained on a laptop CPU, evaluated on a held-out test set with confidence intervals.

0.74ROC-AUC (95% CI 0.70 to 0.77)
65.9%accuracy on 750 unseen images
5,000X-rays, stratified 70/15/15 split
2data-quality traps found and fixed

Honest result: clearly better than chance, but it misses about 4 in 10 caries images. The write-up explains why (resolution loss, no healthy X-rays in the data, a source shortcut I removed) rather than polishing the number.
